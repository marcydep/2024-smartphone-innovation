# Smartphone Innovation Score

This repository contains the R scripts used for the empirical analysis
presented in the master's thesis on smartphone innovation.

The scripts cover the construction of the Innovation Score and its
technological sub-indices, as well as the  and construnction of sentiment 
and statistical analyses of consumer perceptions.

The dataset used in the analysis is not publicly available. It can be
provided upon reasonable request for academic and research purposes.

## Contents

- `Innovation_Score.R` – construction of the Innovation Score and its
  technological dimensions.
- `Sentiment_Analysis.R` – analysis of consumer reviews and perceived
  smartphone performance.
- `Sentiment.py` - code and prompt used to obtain sentiment values
- `...` – additional scripts used for the empirical analysis.


## Data

The underlying dataset combines information collected from multiple
sources, including publicly available technical specifications and
consumer reviews.

The dataset is not included in this repository.
